# Premium Automotive Market Analytics  

Exploratory data analysis project on the Brazilian premium automotive market using Python.

## Project Objective  
The goal of this project is to analyze premium vehicle registrations in Brazil and identify relevant market patterns related to brands, models, segments, geography and time.  
The project is being developed as part of a practical Python learnig journey, with emphasis on data analysis fundamentals and clear business interpretation.  

## Data Source  
The project will use public automotive market data, initially sourced from FENABRAVE.  
The final dataset structure will be defined after evaluting the available files and theis level of detail.  

## Technologies  
- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- Jupyter Notebook
